# rdr2-assets

Тайлы подложки для интерактивной карты [Red Dead Redemption 2](https://broskiplay.ru/rdr2-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<z>/<x>/<y>.webp` (512×512, z0–z6, WebP q95) и `tiles/manifest.json` — список существующих тайлов
- Подложка собрана из официальной карты Rockstar Games (тайлы z1–z7, склеены по 2×2).
